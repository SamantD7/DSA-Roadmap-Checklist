# DSA Roadmap Checklist

A sleek, interactive, and fully offline-friendly Data Structures & Algorithms (DSA) study planner and progress tracker.

---

## Features

- **Structured Roadmap:** All essential DSA topics, broken down by phases and detailed subtopics.
- **Checklist UI:** Mark subtopics as complete. Progress bar updates automatically.
- **Personal Notes:** Write custom notes and attach LeetCode problem references to each subtopic.
- **Custom Topics/Subtopics:** Add your own topics and subtopics anytime.
- **Deadline Tracking:** Set a target date and see required pace per week/day.
- **Pacing Analytics:** Automated calculations for subtopics/day or week needed.
- **Persistent Progress:** All your progress, notes, and customizations are saved locally in your browser (no sign-in needed, 100% local).
- **Responsive Design:** Works great on mobile and desktop.
- **Safe Reset Options:** Reset progress or wipe everything (including notes/custom topics).
- **LeetCode Integration:** Quick add and external link for LC problems.
- **Offline Ready:** Works completely offline—perfect for focused study.
- **Lightweight:** Only a single self-contained HTML file (no external JS, only loads fonts).

---

## Usage

1. **Open the app:**  
   Just open [`dsa_roadmap_checklist.html`](dsa_roadmap_checklist.html) in your web browser.

2. **Track your progress:**  
   Check off subtopics, add notes, attach LC problems, and set a target date to pace your prep.

3. **Add custom content:**  
   Use the "+ Add Topic/Subtopic" buttons to expand or customize your roadmap.

4. **Data privacy:**  
   Everything is stored _locally_ in your browser (`localStorage`). Nothing leaves your device.
